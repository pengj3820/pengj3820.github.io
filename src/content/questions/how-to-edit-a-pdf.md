## First: what kind of edit do you need?

| I want to… | Easiest free tool |
|---|---|
| Add text, highlight, draw, add notes | Edge, Preview, Acrobat Reader |

## Add text and annotations (free)

**Windows — Microsoft Edge**
1. Right-click the PDF > Open with > Microsoft Edge.
2. Use **Add text**, **Draw** or **Highlight** in the toolbar.
3. Click **Save** (or Save as).

**Mac — Preview**
1. Open the PDF in Preview.
2. Click the **Markup** (pen) icon.
3. Use the **T** (text box), shapes, highlight or signature tools.

**Any computer — Adobe Acrobat Reader (free):** use *Comment* or *Fill & Sign* to add text and marks.

## Change the existing text

### Method A: Microsoft Word (best for text documents)
1. In Word, choose **File > Open** and select the PDF.
2. Word converts it into an editable document. Complex layouts may shift.
3. Make your edits, then **File > Save As > PDF**.

### Method B: Google Docs (free, any device)
Upload to Google Drive, right-click > **Open with > Google Docs**. Best for simple text. Layouts and images are often lost.

### Method C: LibreOffice Draw (free, desktop)
Opens PDFs as editable pages where each text line is a box. Good for small fixes that keep the layout.

### Method D: Online PDF editors
Many online editors let you click on existing text and change it. Good for typos and small changes. Mind privacy for sensitive files.

## The "white-out" trick for tiny fixes

If nothing else works (e.g. on a scan): draw a **white rectangle** over the wrong text, then add a **text box** with the correct text on top. Match the font size as closely as you can.

> ⚠️ White-out only hides content visually. The original text may still be in the file and can be copied. Never use it to hide confidential information. Use a proper **redaction** tool instead.
