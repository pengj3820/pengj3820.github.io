## Match your error to the fix

| Symptom | Likely cause | Fix |
|---|---|---|
| "File is damaged and could not be repaired" | Incomplete download or corrupted transfer | Re-download; ask the sender to resend |
| "Please wait… If this message is not eventually replaced…" | XFA form | Open in **Adobe Acrobat Reader desktop** |
| Asks for a password | Encrypted PDF | See [Remove a PDF password](/questions/remove-pdf-password/) |
| Blank or grey pages | Viewer rendering issue, huge images | Try another viewer; update your reader |
| "Not a supported file type" | Not really a PDF, or wrong extension | Check the file size; ask the sender |
| Nothing happens on double-click | No default PDF app set | Right-click > Open with > a browser |
| Opens but is missing text | Fonts not embedded | See [PDF fonts look wrong](/questions/pdf-fonts-look-wrong/) |

## Step-by-step troubleshooting

1. **Try a browser.** Drag the file into Chrome, Edge or Firefox. They have robust built-in viewers.
2. **Re-download.** Compare the file size with what the sender expects. A 0 KB or tiny file is broken.
3. **Update or reinstall** Adobe Acrobat Reader.
4. **Copy it locally.** Files opened directly from email, network drives or cloud sync folders sometimes fail. Save to the desktop first.
5. **Check the extension.** A file named `.pdf` might actually be something else. Very small files or odd icons are clues.
6. **Rebuild the PDF.** If it opens anywhere at all, use **Print > Save as PDF** to create a clean copy.

## Setting a default PDF app

- **Windows:** Settings > Apps > Default apps > search ".pdf" > choose Edge or Acrobat Reader.
- **Mac:** right-click a PDF > Get Info > *Open with* > Preview > **Change All…**
